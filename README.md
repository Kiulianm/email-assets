# email-assets

Publicly hosted KeRSNet logo files.

- `kersnet-logo-full.png`: cropped and sized for email signatures (600 x 492 px)
- `kersnet-logo-570.png`: cropped logo, 570 px wide
- `kersnet-logo-original.png`: full-resolution PNG (2340 x 1800 px)
- `kersnet-logo-print.jpg`: high-resolution JPG for print (6500 x 5000 px)
- `kersnet-logo.svg`: scalable vector for web and slides (not supported in email signatures)

Do not rename or delete these files. Sent emails and other documents link to them.
